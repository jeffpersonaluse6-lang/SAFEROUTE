# SafeRoute - Campus Evacuation Navigator

BPNHS campus evacuation routing app. Download the APK below.

## Download

**[SafeRoute.apk](SafeRoute.apk)** (43.8 MB)

## Features
- Multi-floor stair routing with same-well continuation
- Safety-prioritized evacuation gate selection
- Active shooter, fire, and earthquake hazard simulation
- Real-time rerouting around hazards
- Step-by-step evacuation guidance overlay
- Road-preferred pathfinding with centerline network
